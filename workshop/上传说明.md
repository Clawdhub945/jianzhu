# 创意工坊上传说明

## 包结构（已就绪）

```
workshop/JianZhu/
  About/About.xml            # 名称/作者/描述/版本（modVersion 会自动同步 Plugin.cs）
  About/Preview.png          # 预览图 563x658
  About/PublishedFileId.txt  # 首次上传后 Steam 会写入物品 ID（之后更新必须带上）
  Defs/stuff.json build.json tech.json
  Assemblies/JianZhu.dll
```

## 更新包内容

改完代码/Defs 后：

```bash
dotnet build -c Release --no-restore
python _tools/make_defs.py        # 仅改了 Defs 时
python _tools/pack_workshop.py    # 刷新 DLL+Defs+版本号到工坊包
```

## 首次上传（steamcmd）

1. 写一个 `upload.vdf`：

```
"workshopitem"
{
    "appid"           "1455910"
    "publishedfileid"  ""
    "contentfolder"    "C:\AI\mod\jianzhu\workshop\JianZhu"
    "changenote"       "0.6.2 初版发布"
    "title"            "大通铺（多人床位·可配置容量）"
    "description"      "见 About.xml 描述，可自行润色"
}
```

2. `steamcmd +login <你的steam账号> +workshop_build_item <upload.vdf 路径> +quit`
3. 上传成功后 Steam 给出物品 ID → 填进 `About/PublishedFileId.txt` 和 upload.vdf 的 publishedfileid
4. 之后的更新：改 changenote，重复 workshop_build_item 即可
